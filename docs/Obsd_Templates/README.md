# Obsidian Templates

Templater templates for maintaining consistent FORGE-v6 documentation structure.

## Available Templates

- [README-Navigation.md](README-Navigation.md) - Basic navigation README
- [README-Section.md](README-Section.md) - Detailed section README with components

## Usage

In Obsidian with Templater plugin:
1. Create new file or open existing README.md
2. Open command palette (`Cmd+P` / `Ctrl+P`)
3. Select "Templater: Insert Template"
4. Choose template

## Pattern Guidelines

**Standard markdown links only:**
```markdown
[Display Text](relative/path/to/file.md)
```

**NOT Obsidian wiki-links:**
```markdown
[[path|text]]  ❌ Don't use
```

**Structure:**
- Minimal fluff
- Maximum navigation
- Clear hierarchy
- Brief descriptions
